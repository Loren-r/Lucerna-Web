Sitio web para un emprendimiento de velas artesanales con formas originales, especialmente de postres: cupcakes, tortas, donas y más.

Es uno de mis primeros proyectos web. Lo hice para aprender a construir una página desde cero, resolviendo una necesidad real: darle una vitrina en línea a un emprendimiento pequeño.

Objetivo

Mostrar el catálogo de velas de forma atractiva, para que las personas conozcan los productos y puedan contactar al emprendimiento para comprar.

Funcionalidades
Página de inicio con la presentación del emprendimiento.
Catálogo de productos con fotos, nombre y descripción.
Sección de contacto.
Construcción de tu vela personalizada.

CSS
